This Command is use to run the Arduino file from the CLI
```
Compilation Syntax -> Compile.bat 'D:\Coding\IOT\MyProject' COM4 12 2
```
The following Command are: <hr>
```
COM4 -> is your commucation port
12 -> is your thread to be assigned
2 -> is the PSRAM enable/diasble
```
